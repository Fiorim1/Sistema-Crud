🚀 Projeto CRUD — React, Node.js e MySQL

Este projeto demonstra de forma prática o funcionamento completo de um CRUD (Create, Read, Update, Delete), integrando React no front-end, Node.js (Express) no back-end e MySQL como banco de dados.

O objetivo é apresentar de forma simples e didática como ocorre a comunicação entre o cliente, o servidor e o banco de dados, cobrindo todas as operações básicas de manipulação de dados.

🧩 Tecnologias Utilizadas

React.js — Interface do usuário (Front-end)

Node.js + Express — Servidor e API (Back-end)

MySQL — Banco de dados relacional

Yarn — Gerenciador de pacotes

⚙️ Pré-requisitos

Antes de iniciar o projeto, verifique se possui instalado em sua máquina:

Node.js

Yarn

MySQL

📦 Instalação das Dependências

No diretório raiz do projeto (e também dentro das pastas frontend e backend, se houver separação), execute o comando abaixo para instalar todas as dependências necessárias:

yarn install

▶️ Como Executar o Projeto <br>
🔹 Back-end

Acesse a pasta do servidor (back-end):

cd api


Inicie o servidor:

yarn start


🔹 Front-end

Acesse a pasta do front-end:

cd front


Inicie o projeto React:

yarn start


O aplicativo abrirá automaticamente em:

http://localhost:3000

🗄️ Configuração do Banco de Dados

Arquivo sql crud.mwb

🧠 Conceito Aplicado

O projeto segue o princípio CRUD, permitindo:

Create → Inserir novos registros

Read → Consultar dados existentes

Update → Editar informações já salvas

Delete → Remover registros do banco de dados
